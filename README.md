# CLA signatures

This branch only stores the Contributor License Agreement signatures collected by the CLA bot
(`.github/workflows/cla.yml` on `main`) in `signatures/version1/cla.json`.

Do not protect or delete this branch: the bot commits signatures to it with the workflow token.
The agreement itself is [CLA.md](https://github.com/lajstrom/lajstrom/blob/main/CLA.md) on `main`.
