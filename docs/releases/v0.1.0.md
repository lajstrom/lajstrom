# Lajstrom v0.1.0: release notes (draft)

> Draft for #59, to be finished on the release day: the date, the rc results, the final list of
> registries and anything that lands before the freeze on 2026-12-03. The goreleaser changelog
> (commits by type) and the "Verify" footer of `.goreleaser.yaml` are appended to these notes on
> the release page.

Lajstrom is an artifact registry on top of the OCI registry you already run. One server serves
raw files, pypi, apt, maven and npm repositories, and stores every artifact as an OCI artifact in your
registry. It owns no bytes, only an index, and the index can always be rebuilt from the
registry. v0.1.0 is its first release with functionality.

## What works

| Area | What v0.1.0 does | Guide |
| --- | --- | --- |
| raw | `curl -T` in, `curl` out; every upload a version, addressed by its digest | [quick start](../quickstart/raw.md) |
| pypi | `twine upload`, `uv publish`; `pip`, `uv` and Poetry install from the simple index (PEP 503, PEP 691, PEP 658) | [quick start](../quickstart/pypi.md) |
| apt | `.deb` in with `curl` or `oras push`; `apt-get update` and `install` from a signed repo, with by-hash indexes | [quick start](../quickstart/apt.md) |
| maven | `mvn deploy` and Gradle `publish`; resolution with `maven-metadata.xml` and all four checksums | [quick start](../quickstart/maven.md) |
| npm | `npm publish`, `npm install`, dist-tags, `npm deprecate` and `unpublish`, `npm login` | [quick start](../quickstart/npm.md) |
| Proxy and group | npm only: a proxy repo of npmjs.org, cached in your registry, with an offline mode; a group of a hosted repo and a proxy under one URL | [proxy-and-group.md](../spec/proxy-and-group.md) |
| OCI | `oras`, `docker` and `crane` through the `/v2` facade; `oci` pass-through repos; referrers, so cosign signs and verifies, `oras discover` lists | [quick start](../quickstart/oras.md) |
| Users and access | local users, personal access tokens, deploy tokens; roles on repo masks; anonymous read per repo; throttled failed logins | [auth.md](../auth.md) |
| Management | `/api/v1` with an OpenAPI document; the `lajstrom admin` CLI; an audit log | [api.md](../api.md) |
| Operations | SQLite or Postgres; `reindex` from the registry; metrics; drain on shutdown; retries and a circuit breaker toward the registry | [operations.md](../operations.md) |
| Install | binaries for linux and darwin (amd64, arm64), a distroless image on ghcr.io and Docker Hub, a Homebrew cask; all signed with cosign, with SBOMs | [install.md](../install.md) |
| Deploy | a production Docker Compose example, Kubernetes manifests, nginx and Caddy in front, backup and restore | [deploy](../deploy/compose.md) |

## What does not work yet

- Formats other than raw, pypi, apt, maven, npm and OCI: rpm (#64), terraform modules (#66).
- Proxy and group repositories of pypi and maven (#67, #68); npm has them.
- OIDC login and groups (#69); a web UI (#70). Retention, `lajstrom admin retention` over a
  conditional delete (#72), is planned for v0.1.0: on the release day it is here or in "What works".
- maven SNAPSHOT versions (#80), pypi yanking (#81), apt source packages (#79).
- ECR measured against a live account (#19).

## Known limitations

- **API stability.** It is not guaranteed before 1.0: the HTTP API, the configuration and the CLI may change between 0.x versions ([our promise](../../README.md#our-promise-to-users)).
- **Throttles.** The throttles of failed logins and of `/v2/token` count per replica. The edge is the bound across replicas ([reverse-proxy.md](../reverse-proxy.md)).
- **The audit log** only grows: there is no retention or export yet. It is part of the backup of the index.
- **Upgrades.** From this release on, migrations are expand or contract: a rolling update to the next release works, and the notes of a release with a contract migration say what it needs ([operations.md](../operations.md#upgrades)); a build from before v0.1.0 does not check the schema it runs on.
- **`server.externalURL`** must be https; plain http is accepted only on a loopback host, with `server.insecureHTTP: true`.
- **Uploads are bounded by default** (#246). A file above its format's size is `413`: npm 512 MiB, pypi and maven 4 GiB, apt and raw 8 GiB; a repo's `policy.maxFileSize` sets another size, higher or lower ([api.md](../api.md#policy)). A replica runs 32 uploads at once (`server.maxConcurrentUploads`, `0` lifts it), a principal holds at most 256 live `/v2` upload sessions of a repo and 1024 of all repos on a replica (`server.uploadSessions`), and a Maven deploy stores at most 256 files (`policy.maven.maxSessionFiles`). [operations.md](../operations.md#requests-from-clients) lists every bound.
