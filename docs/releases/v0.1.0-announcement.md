**Title (Show HN):** Show HN: Lajstrom – apt, rpm, pypi, maven, npm and raw repositories on top of your OCI registry

---

Most teams already run an OCI registry: ECR, Harbor, GHCR, Zot, plain distribution. Next to it
they often run a second system for packages (Nexus, Artifactory, a bucket with a script), with
its own storage, backups and permissions.

Lajstrom is one Go binary that serves apt, rpm, pypi, maven, npm and raw-file repositories, and
stores every package as an OCI artifact in the registry you already have. It owns no bytes. Its
only state of its own is an index (SQLite or Postgres) and the users and permissions, and the
index can be rebuilt from the registry at any time.

What v0.1.0 does:

- `twine upload` and `pip install`; `mvn deploy` and Gradle; `npm publish` and `npm install`
  (pnpm and yarn too), with a caching proxy of npmjs.org; `.deb` uploads and `apt-get install`
  from a signed repo; `.rpm` uploads and `dnf`, `yum` or `zypper` from a GPG-signed repo;
  `curl -T` for anything else. All of it uses the clients' own protocols, with no plugins.
- `/v2` in front of the registry with Lajstrom's own users and roles, so `oras`, `docker` and
  `cosign` work with the same tokens. Signatures and SBOMs are stored as referrers. An `oci`
  proxy repo is a pull-through cache of Docker Hub, ghcr.io, quay.io or another registry, for
  docker, containerd and Talos nodes.
- Local users, personal access tokens and deploy tokens for CI, OIDC login with the identity
  provider's groups bound to roles, roles on repo masks, an audit log.
- Signed binaries and images with SBOMs, a Homebrew cask, a Helm chart, Compose and Kubernetes
  examples.

Tested against distribution and Zot on every code change, and by hand against GitLab's
registry, GHCR, Harbor, Nexus, Gitea, Forgejo, Amazon ECR, JFrog Container Registry and Project
Quay (the release notes give the limits). Not yet: proxy repositories for pypi, maven, apt and
rpm, LDAP and SAML, a UI. The list is in the release notes.

It is Apache-2.0. Before 1.0 the API may still change, but releases come on a schedule and the
license stays (the README has the promise).
