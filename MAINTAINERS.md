# Maintainers

| GitHub handle | Role |
| --- | --- |
| [@gecube](https://github.com/gecube) | maintainer, project lead |

## Responsibilities

Maintainers review and merge pull requests, triage issues, decide on ADRs and on exceptions to the
dependency license policy, handle security reports ([SECURITY.md](SECURITY.md)) and enforce the
[Code of Conduct](CODE_OF_CONDUCT.md).

## Becoming a maintainer

1. An existing maintainer nominates a contributor in a pull request that adds them to the table above.
2. The nominee has contributed in a sustained way for at least two months: code, reviews,
   documentation, design discussion or issue triage.
3. The nomination is accepted by lazy consensus: if no maintainer objects within one week of the
   pull request being opened, it is merged. Any objection is discussed and resolved first.

Maintainers who are no longer active may step down at any time, or be moved to an emeritus list by
the same lazy-consensus process after six months of inactivity.
