{{- $url := .Values.config.server.externalURL | default "" -}}
Lajstrom {{ include "lajstrom.tag" . }} runs as the Deployment {{ $full }} in the namespace {{ $ns }},
behind the Service {{ $full }} (port http {{ .Values.service.port }}), for {{ $url }}.

  kubectl -n {{ $ns }} rollout status deploy/{{ $full }}

The replicas start once these Secrets exist (docs/deploy/helm.md):
  {{ include "lajstrom.secretName" (dict "root" . "ref" .Values.masterKey) }}: {{ .Values.masterKey.key }}, the master key
  {{ include "lajstrom.secretName" (dict "root" . "ref" .Values.database) }}: {{ .Values.database.key }}, the Postgres DSN
{{- range .Values.registryPasswords }}
  {{ include "lajstrom.secretName" (dict "root" $ "ref" .) }}: {{ .key }}, {{ .env }}
{{- end }}
{{- if .Values.bootstrap.enabled }}
{{- $boot := include "lajstrom.bootstrapSecretName" . }}

The first admin, from a machine that reaches {{ $url }}, with the token of the Secret {{ $boot }}:

  lajstrom admin bootstrap --server {{ $url }} --name admin \
    --token-file <(kubectl -n {{ $ns }} get secret {{ $boot }} -o jsonpath='{.data.{{ .Values.bootstrap.key }}}' | base64 -d)

Then the token is dead: kubectl -n {{ $ns }} delete secret {{ $boot }}
{{- end }}
